## 已知边界与风险

1. 安装包与可执行文件未做代码签名，Windows SmartScreen 可能提示“未知发布者”。
2. 宿主启动动画的真实验收目前仅覆盖 ZCode；多显示器、原生 OS 键鼠及其他宿主不能据此视为已验收。
3. 换肤与启动注入依赖宿主开放调试端口；宿主版本、页面结构、CSP 或进程模型变化后，必须重新验证身份识别、应用和恢复。
4. 自定义宿主必须逐一试穿验证；自动发现或接入成功不代表所有窗口、媒体和明暗模式均已覆盖。
5. 当前环境的可选 `ffmpeg` / `ffprobe` 功能未在本轮内核测试中覆盖。
6. 历史验收证据继续保留用于追溯，但当前交付是否有效，必须以本轮代码、构建结果和真实环境复核为准。
